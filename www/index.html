BareHTTP

A from-scratch multi-threaded HTTP server in C.

This page is being served by approximately 300 lines of C that I wrote from scratch. No frameworks, no libraries beyond the POSIX standard. Just sockets, threads, and the C standard library.

What it is

BareHTTP is a static HTTP/1.0 file server. It listens on a TCP port, accepts incoming connections, parses HTTP requests, and serves files from a directory on disk.

The point of building it is not to compete with nginx. It is to understand what an HTTP server actually does at every layer, from the TCP three-way handshake up to the application protocol.

How it works

The server uses a fixed pool of pthread workers and a bounded task queue with mutex + condition variable synchronization.

The main thread does one thing: it calls accept() in a loop and submits each accepted client file descriptor to a thread-safe queue. Worker threads consume from the queue and handle the actual request processing in parallel.

This is the textbook producer-consumer pattern. The queue uses two condition variables — one for "not empty" (consumers wait on it) and one for "not full" (the producer waits on it). Each operation signals the opposite condition after modifying the queue.
